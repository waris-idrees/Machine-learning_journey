# Exploratory Data Analysis (EDA)

## EDA Steps

1. Understand the Dataset
2. Check Dataset Shape
3. Check Column Names
4. Check Data Types
5. Check Basic Statistics
6. Analyze Numerical Features
7. Analyze Categorical Features
8. Analyze Data Distribution
9. Analyze Relationships Between Features
10. Check Correlation
11. Visualize Important Patterns
12. Identify Key Insights
13. Summarize Findings

## Common Visualization Techniques

- Histogram
- Box Plot
- Scatter Plot
- Bar Plot
- Count Plot
- Heatmap
- Pair Plot

## Goal

Understand the dataset, discover patterns and relationships, and extract meaningful insights before further Machine Learning steps.
