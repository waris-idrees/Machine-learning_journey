# Dataset Overview

The dataset used in this project contains a large amount of raw data. During the initial analysis, several data quality issues were identified.

The dataset contains:

- Missing values in multiple columns
- Duplicate records
- Different data types
- Numerical and categorical features
- Some inconsistent or unnecessary values

Because the dataset contains a significant amount of missing and duplicate data, it requires proper cleaning before it can be used for further analysis and Machine Learning.

The purpose of this section is to examine the quality of the dataset and prepare a clean and reliable version for the next stages of the Machine Learning workflow.

## Dataset Challenges

The main challenges identified in the dataset include:

- High number of missing values
- Duplicate rows
- Incomplete records
- Data quality issues

A clean dataset is important because poor-quality data can affect analysis and Machine Learning model performance.

## Project Workflow

Raw Data → Data Cleaning → Data Preprocessing → Feature Engineering → Model Training → Model Evaluation
