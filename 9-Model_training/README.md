# Model Training

## What is Model Training?

Model Training is the process of **teaching a Machine Learning model to learn patterns and relationships from training data** so that it can make predictions on new data.

## How Does Model Training Work?

1. Prepare the dataset.
2. Split the data into training and testing sets.
3. Select a suitable Machine Learning algorithm.
4. Give the training data to the model.
5. The model learns patterns from the training data.
6. The trained model is then used to make predictions.
